# Linux on the Nokia 6303 classic

Linux 6.12 and BusyBox, launched from a Java ME app without flashing the phone.
Reboot to return to S40.

The Nokia port lives in [`s40/`](s40/README.md): build instructions, USB shell
setup, hardware support and source layout. It uses the
[S40 homebrew SDK](https://github.com/s40homebrew/s40).

The rest of this tree is upstream Linux 6.12. See the original
[kernel README](README) for upstream documentation.
